## What I do

I have been writing code on GitHub since 2018. Most of it is backend Python: async services, Telegram bots and userbots, API clients, data validation. When Python gets too slow, I move the hot path to Rust and bind it back with PyO3.

I care about what happens after the merge: strict linting, typed code, tests that pin behaviour, reproducible builds, CI that fails for a real reason and stays green. My own server runs NixOS, declared from a single repository.
